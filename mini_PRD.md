## Mini PRD: Persistence Model-Zoo Follow-up

### Objective

Clean up the behavioral model-zoo analysis before connecting any computational variables to the L21/L22 persistence subspace.

The current run shows that behavioral persistence is highly predictable, but two issues prevent clean interpretation:

1. the report ranks a **Foraging-only MVT-like model** as the overall winner even though it is not a three-task model;
2. the **flexible linear model outperforms the MLP/GRU**, so the GRU cannot currently be treated as a behavioral ceiling.

The autogenerated report currently describes the observable GRU as \(R^2=.737\) and the Foraging-only MVT model as the best interpretable model. 

---

# 1. Fix model ranking

Separate results into:

### A. Cross-task models

Eligible only if evaluated on:

* Bandit
* Foraging
* Solvability

Rank these by macro held-out persistence-logit performance.

### B. Task-specific models

Rank separately within each task.

For example:

```text
Best Bandit model
Best Foraging model
Best Solvability model
```

**Do not compare a one-task model directly against a three-task model in the overall ranking.**

Add a regression test that deliberately supplies a one-task model with excellent performance and verifies that it cannot become `best_cross_task_model`.

---

# 2. Diagnose the neural “ceiling”

The flexible linear model currently performs better than both the MLP and GRU despite the neural models having access to the same broad observable feature set.

Before interpreting the GRU as a ceiling, establish that the neural pipeline can reproduce a linear solution.

### Required sanity test

Generate or use a dataset where:

$$
y=X\beta+\epsilon.
$$

Require:

$$
R^2_{\mathrm{MLP}}
\approx
R^2_{\mathrm{linear}}
$$

and:

$$
R^2_{\mathrm{GRU}}
\geq
R^2_{\mathrm{linear}}-\epsilon
$$

for a predefined tolerance such as:

```yaml
neural_linear_recovery_tolerance_r2: 0.02
```

If this fails, debug:

* feature scaling;
* target scaling;
* episode weighting;
* sequence masking;
* padding;
* loss computation;
* learning rate;
* early stopping;
* train/validation handling;
* output-layer initialization.

Do not expand the neural hyperparameter search substantially until basic linear recovery passes.

---

Report:

Define:

```text
best_flexible_model
```

Do not hard-code GRU as the ceiling.

# 4. Feature-group ablations of the flexible linear model

This is the main new scientific analysis.

Take the strongest **observable cross-task flexible linear model** and divide its predictors into conceptual groups.

Suggested groups:

### History

* previous choice;
* previous outcome;
* action lags;
* outcome lags;
* failure/success streaks.

### Time / effort

* round;
* normalized time;
* cumulative effort/progress variables.

### Continuation value

* estimated continue value;
* relative value.

### Outside option

* estimated outside value.

### Cost

* cost pressure;
* task-specific displayed costs.

### Progress / solvability

* progress evidence;
* displayed progress cues;
* cumulative progress.

### Derived termination variable

* termination advantage / disengagement evidence.

Use the existing feature schema as the authoritative observable/oracle distinction. 

---

# 5. Ablation procedure

Fit the full model:

$$
M_{\text{full}}.
$$

Then refit after removing each feature family:

$$
M_{-H}, M_{-V},M_{-C},M_{-P},...
$$

On the untouched test set compute:

$$
\Delta R^2_g
=
R^2_{\mathrm{full}}
-
R^2_{-g}.
$$

Also report:

$$
\Delta MSE_g
$$

and sampled-choice:

$$
\Delta \text{log loss}_g.
$$

Use episode/pair-clustered bootstrap CIs for each difference.

Run this:

1. pooled/macro across three tasks;
2. separately for Bandit;
3. separately for Foraging;
4. separately for Solvability.

# 9. Decision rule

Do **not** proceed to the L21/L22 neural analysis until:

1. cross-task and task-specific model rankings are separated correctly;
2. MLP/GRU can recover a linear synthetic mapping;
3. the flexible ceiling is established;
4. feature-group ablations are complete.

Then use the strongest computational ingredients—not merely the named model winner—as the targets for interpreting the L21/L22 rank-4 persistence subspace.

The key deliverable should be something like:

> “Cross-task persistence is primarily explained by recent history + progress/cost information, while generic value contributes comparatively little.”

That would give us a much sharper mechanistic hypothesis than simply saying one cognitive model won.
