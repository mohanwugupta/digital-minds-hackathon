# Artifact inventory

The artifact tree contains retained scientific data and generated results. It
is deliberately separate from source code.

## Behavioral and state data

- `bandit_pilot.csv`: 200-episode behavioral pilot.
- `pilot_diagnostics/`: integrity audit and descriptive pilot summaries.
- `activation_bank/`: 512 probe-development episodes with all-layer final-token
  states; source data for TD, Monte Carlo, and ridge probes.
- `confirmatory_state_bank/`: independent 48-episode bank for factorial and
  causal replay.

## Probe data

- `value_probes/`: initial TD metrics, selected frozen probe, diagnostics, and
  Appendix B summaries.
- `mc_value_probes/`: nonlinear Monte Carlo metrics, selected sparse and full
  frozen probes, predictions, and Appendix C summaries.
- `linear_probes/`: per-layer ridge metrics and small checkpoints, selected
  future-return and persistence probes, predictions, and reports.
- `advantage_targets/`: paired counterfactual rollout targets.
- `advantage_probes/`: ridge metrics, selected provisional-advantage probe,
  predictions, and reports.

## Confirmatory results

- `value_dissociation/factorial_shard_*.csv`: complete 4 × 3 incentive
  factorial, including the three frozen native-layer projections used in the
  paper.
- `causal_steering/replays_shard_*.csv`: target and matched-random causal
  interventions.
- `*/publication/`: compact JSON, Markdown, and SVG summaries.
- `mechanism_synthesis/`: cross-experiment computational interpretation.

## Cross-task follow-up

- `value_dissociation/layerwise_projections*.csv`: compact all-layer frozen
  persistence projections for Track A.
- `cross_task/foraging_activation_bank/`: counterbalanced depleting-patch
  episodes.
- `cross_task/control_activation_bank/`: paired number comparisons with no
  persistence semantics.
- `cross_task/foraging_probes/`: within-task linear ceiling.
- `cross_task/transfer/`: strict zero-shot and calibration-only summaries.
- `cross_task/causal/`: validation-only calibration, held-out replays, and
  causal-transfer summaries.

## Regeneration policy

Smoke outputs, per-layer TD/nonlinear checkpoints, the superseded standalone
positive-control replay, and optional factorial all-layer tensors are not
retained. They can be regenerated by the documented pipeline. The factorial
collector saves optional tensors only when `--save-activations` is explicitly
requested.

The activation and confirmatory banks are large but retained because they are
required to retrain probes and reproduce held-out interventions without
regenerating model behavior.
